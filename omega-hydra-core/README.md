# Omega Hydra Core

Executable MVP foundation for the Omega Hydra platform — a provenance-aware, safety-gated knowledge-to-product engine with optional Warp/Oz execution.

## Strategic Rule

Build the functioning platform first, then visualize it as a living city.

```text
Users → Identity → Companion → Mission → Tracking → Product → City Visualization
```

## Skill Forge Pipeline

```text
Source Material
  → Source Normalization + Provenance
  → Framework Extraction
  → Safety / Claims Review
  → Hydra Skill
  → Daily Missions
  → Companion Behaviors
  → Product Templates
  → Hydra Eyes Telemetry
  → Optional Warp/Oz Execution
```

## Quick Start

```sh
cd omega-hydra-core

# Run the Guardian Readiness demo (full pipeline)
npm run skill-forge:demo

# Run the agent control plane demo
npm run agent-control

# Run all tests (32 tests, no network required)
npm test
```

## Public-Safe Operating Scope

Omega Hydra Core is limited to lawful defensive education, privacy awareness, digital hygiene, ethical decision-making, business automation, community service, readiness training, product delivery, and reflective learning.

It does not provide offensive cyber capabilities, weapon instruction, evasion guidance, injury targeting, unauthorized access workflows, or real-world force escalation.
